What the full pipeline adds

  • Durable queue — Postgres FOR UPDATE SKIP LOCKED
  • Idempotency — SHA-256 of the file, never processed twice
  • Audit trail — every status transition recorded
  • Archive — original PDF preserved before extraction
  • Retries — 10s/30s/60s backoff for transient errors
  • Notifications — Slack/Teams webhook or mock feed

This page runs the same extraction and validation rules in JavaScript, with no backend. The repository ships the full Docker stack.
